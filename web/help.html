DayMaker help

Weather

Choose a city or ZIP code, or request device location. If the network is unavailable, check the observation timestamp and cached-data notice. A partial or unavailable precipitation forecast is not a prediction of zero rain. Follow official warning instructions and local authorities.

Memes

Open Fun → Meme Studio, choose a bundled template or import your own photo, then edit the local document. Export shows the result before offering image saving, sharing, or a portable project backup. Browser download requests do not guarantee a file was saved; check your downloads.

Advertising

Test advertising may be shown only in explicitly enabled development builds. No ads are placed in radar, privacy/settings, the editor, or exported images. The plain label “Advertisements” identifies display slots. Interstitials can only be considered after a completed meme result and an explicit Done action, subject to strict limits. An unavailable ad should never stop navigation.

Report an issue

Use the project issue tracker for non-sensitive bug reports. Do not post precise locations, personal photos, private captions, account identifiers, or other personal information in a public issue.
